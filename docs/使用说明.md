# LabPilot 使用说明

这份文档讲**怎么用**。面向三类人：实验室成员、管理员、部署扫码程序的人。
系统结构和技术细节见 [功能导图](./功能导图.md) 和 [技术文档](./技术文档.md)。

---

## 一、这是什么

实验室仪器协作平台：讨论、预约、上机、台账串成一条数据链。

- **预约系统**跑在一台固定机器上，浏览器打开它的网址就能用。
- **每台仪器电脑**装一个扫码程序，负责上机后建文件夹、下机后发数据。
- **用户手机**扫仪器上的二维码，完成登录、上机、下机。

---

## 二、实验室成员：预约 + 上机 + 下机

### 1. 打开网址

浏览器打开预约系统公网地址（形如 `https://xxx.trycloudflare.com`），先出现登录页。

- 已有账号：填姓名登录。**设置过密码的账号要填密码，没设置过就留空。**
- 第一次用：切到「注册」，**姓名必填**，邮箱和密码可以不填。填了密码的账号，登录时要填密码。

### 2. 预约

登录后进入看板。到「预约」页，选仪器、日期、时段，填用途，提交。
时段冲突会当场报出冲突的单号和时段。

### 3. 上机

到仪器前，用手机扫这台仪器的二维码（二维码从管理后台下载，贴在仪器旁）。

1. 手机打开扫码页，登录。
2. 系统判断：**当前时段你有这台仪器的有效预约**时，「开始上机」可以点；没有预约、或这台仪器已有别人在用，按钮是灰的。
3. 点「开始上机」，页面停在「已上机」，**这里没有下机按钮**。

### 4. 下机

做完实验，**再扫同一张二维码**：

1. 页面出现「下机」，可以填一个数据接收邮箱（可以不填）。
2. 填了邮箱：仪器电脑会把这次实验文件夹里的数据（不超过 20MB）发到这个邮箱。
3. 点「下机」，页面显示「已下机」。

> 上机、下机都会自动写进台账，不用手动记。

### 5. 摘要（可选）

在「群聊」页选中一段讨论，点「生成摘要」，会把讨论压成带出处的结论；点结论能跳回原话。

## 三、管理员：后台管理

### 1. 登录后台

用管理员账号登录（初始 `admin` / `admin123`）。**上线前要改掉默认密码。**

### 2. 设备管理

- 列表里每台设备名字下面显示它的**设备 ID**（部署扫码程序时要填这个）。
- 新增设备：填「设备 ID」「名称」等。
- 每台设备的「二维码」按钮：下载这张仪器二维码的 SVG，打印出来贴在仪器旁。二维码内容就是 `{公网地址}/s/{设备ID}`。

### 3. 预约 / 用户管理

- 可查看、修改、取消预约；已上机的预约不能改取消。
- 可查看已注册用户列表。

## 四、部署扫码程序（仪器电脑）

每台仪器电脑装一份。步骤：

1. 下载分支压缩包：`https://github.com/lglunl/lab-scan-agent/archive/refs/heads/feature/presence-register.zip`，解压。
2. 双击 `start.cmd`。**第一次会弹出窗口**，填两样后点「保存并启动」：
   - **设备 ID**：这台电脑对应哪台仪器（管理后台里看到的那串，例如 `inst_fc`）。
   - **密钥**：预约系统 `.env` 里的 `LAB_API_TOKEN`，所有仪器电脑用同一把。
3. 第一次会自动下载便携 Python 并安装依赖，需要能上网。**窗口不要关**。
4. 这台电脑的浏览器打开 `http://127.0.0.1:8787`，显示「仪器电脑已就绪」就对了。这里没有登录、没有上机按钮。

之后：

- 有人在这台仪器上机后，实验文件夹会出现在这台电脑桌面的 `Experiment Data` 里。
- 有人下机并填了邮箱，数据会被发送出去。
- 以后双击 `start.cmd` 不再询问，直接启动。

## 五、常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| 扫码页提示「找不到这台仪器」 | 二维码上的设备 ID 不在系统里 | 在管理后台新增这台设备 |
| 扫码后按钮是灰的 | 当前时段没有你的有效预约，或仪器被占用 | 先预约，或等别人下机 |
| 上机后仪器电脑没建文件夹 | 那台电脑的扫码程序没跑、设备 ID 或密钥不对 | 看黑窗口里是否反复出现「读取仪器状态失败」 |
| 下机填了邮箱却没收到 | 仪器电脑没配发信邮箱 | 在 `config.json` 里填 `smtp_host`、`smtp_from` 等 |
| 扫码程序窗口里的中文是乱码 | 少见，编码问题 | 重新下载压缩包解压再双击 |
